# data/：数据依据与合成数据台账

本目录记录 A 股公告关注看板的全部数据依据、数据源可获取性实测结论、合成数据纪律，以及**全项目唯一的数值口径定义**。

- **基准日：2026-10-17**。本文所有条数、耗时、字段样本均为该日的实测快照。
- 实测结论只在本文的"基准日实测"语境下成立；**代码与测试不得内嵌本文的条数**（会随披露节奏漂移）。
- 复测时更新本文并记明日期，不改写历史结论。

## 二、数据源可获取性记录（六条硬约束，逐条实测）

这六条直接决定实现形态，任何一条被"优化"掉都会造成漏报或错标。

### 约束 1：多股票参数无效 → 必须逐只请求

- 实测请求体 `stock=000001,orgA;300750,orgB;600519,orgC` 只返回**第一只**；
- 换顺序（把 300750 放最前）仍只返回放最前的那只；
- 重复 `stock=` 参数同样无效。
- 耗时实测：5 只串行 **1.31s**（≈260ms/只）。按此估算 50 只≈13s、100 只≈26s；单轮 <60s 的验收口径留有余量。
- **实现口径**：清单逐只请求；不得写"逗号拼接批量"的捷径。

### 约束 2：增量必须重叠 1 天

- `announcementTime` 是**毫秒时间戳**，实测**带真实时分秒**，并非全为 `00:00:00`
  （M1 勘误）。但相当一部分条目恰好落在整点零点：2026-10-15 的 1097 条中 **922 条**
  是 `00:00:00`，2026-10-16 为 1073/1313。零点无法区分"当天 00:00 发布"与"只给日期"，
  按小时切窗仍会漏。
- **实现口径**：`seDate` 起点 = 上次成功抓取日期 − 1 天，终点 = 今天；重复由 `announcementId` 主键吸收。

### 约束 3：去重主键 = `announcementId`

- 实测字段非空且唯一（样本 `1225601360`）。
- `announcementTime` 只当日期使用，不参与"同一时刻"判定。

### 约束 4：`pageSize` 上限 30

- 请求 `pageSize=100` 实测只返回 **30** 条。
- 全市场兜底实测：2026-10-16 全天 **1313** 条、10-15 全天 **1097** 条；30 条/页时约 44 页、≈11s（未计限频延时）。
- **实现口径**：`pageSize=30`，翻页至空页或达到 `totalAnnouncement`；翻页之间同样受限频约束。

### 约束 5：`column=szse|sse|bj` 结果相同

- 实测三值同日均返回 1313 条；沪市 `600519` 与北交所 `920000` 都能用 `szse` 查到。
- `column=fund` 是**独立基金库**，不纳入本工具。
- **实现口径**：单路径抓取，不写三套交易所逻辑。

### 约束 6：失败必须隔离 + 退避

- 接口曾出现 504/502（S10）。
- 全局请求间隔 ≥1s；失败指数退避 1s → 2s → 4s，最多 3 次；
- 单只股票最终失败只影响该只，写入"本次失败清单"，终端与日报提示"本次抓取失败 N 只，结果不完整"。
- **禁止**把接口失败静默当成"该股没有新公告"。

### 其他实测细节

- `searchkey` 查询会在标题里插入 `<em>` 高亮标签，**入库前必须剥离**；落库标题不得含 HTML 标签。
- 30 天窗口（2026-09-17 ~ 2026-10-17）逐类量：日常经营 10992、股东会 3341、中介报告 3312、董事会 2361、股权变动 2299、股权激励 2100、增发 958、公司治理 916、可转债 880、权益分派 437、风险提示 390、解禁 264、首发 223、公司债 183、业绩预告 143、其他融资 96、特别处理和退市 73、三季报 52、补充更正 36、半年报 10、退市整理期 8、澄清致歉 4、配股 2、年报 0、一季报 0、监事会 0。**后三类为季节性 0 量，不是接口坏**。
- 官方类别无独立项的缺口，30 天全市场 `searchkey` 实测：诉讼 **238**、仲裁 **87**、业绩预告 **128**、回购 **1095**、减持 **416**、质押 **420**；`category_gqbd_szsh` + `searchkey=减持` 命中 **399**，证明"类别 ∩ 关键词"可叠加。
  （M1 勘误：初版记录的"诉讼/减持"计数与"`gqbd`+减持 = 747"无法复现，已按冻结台账
  `data/snapshots/volume-ledger-2026-09-17_2026-10-17.json` 更正为上述数值。
  G2「质押关键词未单独计数」由此关闭。）

## 三、合成数据纪律（真值基准）

本题真值分三层，全部**程序化标注、人工只抽查**：

1. **抓取层真值**：冻结真实响应字节（公告列表响应、股票清单、26 类枚举 JS）作为回放样本；真值 = "该响应里有哪些 `announcementId`、按 `pageSize=30` 应翻几页、跨窗口重叠后应剩几条"。标注脚本从原始响应独立复算，**禁止手抄期望值**。
2. **分类层真值**：对冻结条目逐条标注期望 `category / tags[] / risk_level`；标注依据必须是可指认的标题文本（规则包条目），不得凭印象。**反向样例必须有**：标题含"减持"但属于其他事项的样本、未命中任何类别的样本（期望 `unclassified`）、季节性 0 类样本。
3. **日报层真值**：两日冻结快照 → 期望"新增清单 / 消失清单"；首次运行样本的期望"新增 = 0"。

纪律：

- **真值只存输入与期望**，禁止 `observed_*` 一类字段（冻结观测会让基准退化成比对两份预计算答案，引擎全坏也全绿）。
- **不编造公告**：所有样本条目取自实测响应的真实字段值（代码、名称、标题、`announcementId`、日期、PDF 路径），标注为"快照样本"；不得虚构不存在的公告标题、编号或日期。
- **自选清单样例**用真实股票代码与真实 `orgId`（如 `600519/gssh0600519`），但明确标注为"快照样本，非用户真实持仓"；**不得把样例清单表述为任何人的持仓**。
- **不新增字段**：合成只做"选哪些条目进样本集"与"期望标签"，不改写响应字段形态。
- **反向样例白名单**：故意构造的非法输入（缺失 `orgId`、未知分组、含 `<em>` 的标题、空响应、5xx 响应）集中登记在本节，测试中按名单逐条覆盖。
- **确定性生成**：标注产物不含系统时钟与随机数；同一输入重跑逐字节一致。

## 四、数值口径（全项目唯一定义处）

> 题面、模块详设、代码常量、README 若出现下列数值，一律以本表为准；出现第二份表述即为缺陷。

| 口径 | 值 | 说明 |
|---|---|---|
| 单轮全局请求间隔 | ≥1s | 所有请求（公告、清单、PDF）统一计时，不按接口分别放松 |
| 重试退避 | 1s → 2s → 4s，最多 3 次 | 仅对可重试错误（超时、5xx、连接中断）；4xx 不重试 |
| `pageSize` | 30 | 实测服务端上限 |
| 增量窗口 | 上次成功日期 − 1 天 → 今天 | 日期精度，重叠由主键吸收 |
| 去重主键 | `announcementId` | SQLite `UNIQUE` |
| 默认自选规模 | 20–100 只 | 设计目标；超出不做性能承诺 |
| 单轮时长门槛 | < 60s（50 只） | 验收口径 |
| PDF 文本抽取范围 | 前 3 页 | 超出不抽，避免整本解析 |
| 首次运行语义 | 静默建基线，新增 = 0 | 第二次运行起做昨日对比 |
| 风险分级枚举 | `high` / `mid` / `low` | 冲突优先级 high > mid > low |
| 风险分级规则 | 见下表 | 产品自定筛选标签，非监管评级、非投资评级 |
| 通知默认值 | `none`（关闭） | 三选一：桌面 / 邮件 / webhook |
| 官方类别数 | 26 | 来源 S6；缺 4 类用关键词补丁 |
| 补丁类别 | 诉讼·仲裁 / 减持 / 回购 / 质押 | 输出到 `tags[]`，不生成官方类别 |

### 风险分级规则表（产品自定，M3 落地时逐条对应规则包字段）

| 级别 | 触发（任一命中） |
|---|---|
| `high` | 特别处理和退市（`category_tbclts_szsh`）、退市整理期（`category_tszlq_szsh`）、风险提示（`category_fxts_szsh`）、澄清致歉（`category_cqdq_szsh`）、诉讼·仲裁补丁、减持补丁、质押补丁 |
| `mid` | 业绩预告（`category_yjygjxz_szsh`）、增发（`category_zf_szsh`）、配股（`category_pg_szsh`）、可转债（`category_kzzq_szsh`）、股权变动（`category_gqbd_szsh`）、解禁（`category_jj_szsh`）、补充更正（`category_bcgz_szsh`）、回购补丁 |
| `low` | 其余官方类别（年报/半年报/一季报/三季报、权益分派、董事会、监事会、股东会、日常经营、公司治理、中介报告、首发、股权激励、公司债、其他融资）与 `unclassified` |

> 该表是**筛选优先级**，不是对公告影响方向的判断；禁止在日报中据此写"利好/利空"。

## 六、目录约定

| 路径 | 内容 | 是否入库 |
|---|---|---|
| `data/snapshots/` | 冻结的真实响应样本（公告列表、股票清单、枚举 JS） | ✅ 入库（脱去无关字段后逐字节冻结） |
