# 00：总览与决策记录

- 仓库：`10-17-cninfo-watch`（A 股公告关注看板：自选清单 → 巨潮公告增量 → 分类日报）
- 版本：v1（题面定稿与骨架 2026-10-17；全部实测结论基准日 2026-10-17）
- 性质：**不参赛项目题**，发布 GitHub **公开仓库**，署名 yuluo554
- 形态：纯本地 Python CLI + 本地日报（Markdown + 单文件 HTML）；单进程 + SQLite，无服务器、无 GPU
- 方法论：按 `ai-tool-project-sprint` 分阶段推进（plan 先行 → 数据先行 → 抓取 → 规则 → 日报 → 归档 → 发布）

**定位宣言**：维护 20–100 只自选股 → 定时增量拉巨潮公告 → 按官方 26 类枚举 + 关键词规则打标 + 风险分级 → 生成"股票 × 类别"双视图本地日报。**只做公开信息聚合，不构成投资建议**。竞品都停在"爬虫/下载 PDF"层：没有人做"自选清单为输入 + 官方类别全集 + 本地日报产物"。

## 决策记录（含弃选项）

| # | 决策 | 理由 | 日期 |
|---|---|---|---|
| D1 | 数据源 = 巨潮资讯网公告查询接口 + 股票清单 JSON + 官方 26 类枚举 | 三处均实测可直连；枚举是官方页面自身使用的类别全集，不需要自己发明分类体系 | 2026-10-17 |
| D2 | **弃"基金季报方向"** | 巨潮基金栏目对 Q3 收录滞后（实测窗口内未齐）；东方财富同类数据存在 ToS 风险；季报本身低频，撑不起"增量看板"的日常使用 | 2026-10-17 |
| D3 | **弃"要素价格看板"** | 已有 60s 级、5820★ 的成熟项目，形态被降维；且组合内无需求证据 | 2026-10-17 |
| D4 | **弃"多股票参数批量请求"** | 实测 `stock=000001,orgA;300750,orgB;600519,orgC` 只返回第一只，换顺序仍只认第一只，重复参数同样无效 → 清单逐只请求是唯一可行路径 | 2026-10-17 |
| D5 | **弃"三交易所三套逻辑"** | 实测 `column=szse/sse/bj` 返回完全相同结果（同日均 1313 条，沪市与北交所标的都能用 `szse` 查到）→ 单路径抓取，省掉三倍维护面 | 2026-10-17 |
| D6 | **弃"公开再分发 PDF / 全文"** | 公告原文版权与平台条款风险；首期只存标题、日期、类别、链接；附件仅用户显式开启时本地落盘 | 2026-10-17 |
| D7 | 分类 = 官方 26 类枚举 + 关键词补丁，**零 LLM** | 类别是官方枚举、标题是结构化短文本，规则可完全复现；LLM 会引入不可复现与外部依赖，与"本地确定性工具"定位冲突 | 2026-10-17 |
| D8 | 关键词补丁覆盖诉讼/仲裁、减持、回购、质押四类 | 这四类在官方 26 类枚举里没有独立项；30 天全市场 `searchkey` 实测诉讼 238、减持 416、回购 1095、业绩预告 128，证明"关键词可检索"；**质押未单独计数（⬜，M1 补测）**。补丁输出 `tags[]`，不伪造官方类别 | 2026-10-17 |
| D9 | 去重主键 = `announcementId`；`announcementTime` 只当日期 | `announcementTime` 只有日期精度（00:00:00），按时间做"同一时刻"判定必然误判；`announcementId` 实测非空且唯一 | 2026-10-17 |
| D10 | 增量窗口 = 上次成功日期 − 1 天 → 今天 | 日期级精度 + 披露延迟，重叠 1 天是唯一不漏的保守口径；重复由主键吸收 | 2026-10-17 |
| D11 | 请求体用 `pageSize=30` 翻页 | 请求 100 实测只返回 30；按实测上限设计，避免"以为拿全了" | 2026-10-17 |
| D12 | 全局 ≥1s/请求 + 指数退避 + 单只失败隔离 | 站点无显式 robots 规则（`robots.txt` 404）≠ 授权；单点失败不得让整轮结果被当成"无新增" | 2026-10-17 |
| D13 | `announcementType` 数值码**不参与分类** | 数值码与 26 枚举的映射未核对（⬜），据码猜类别会系统性错标；首期用 M1 逐类别查询标定的标题规则 | 2026-10-17 |
| D14 | 首次运行静默建基线 | 否则首次日报会把窗口内历史公告全部刷成"新增"，用户第一次打开就失去信任 | 2026-10-17 |
| D15 | 日报双产物 = Markdown + 单文件 HTML（零外链资源） | Markdown 便于二次处理，HTML 便于双击查看；单文件避免本地资源丢失 | 2026-10-17 |
| D16 | 运行时依赖：标准库 + 可选 PyMuPDF/pdftotext | 抓取与日报零第三方依赖即可跑；PDF 文本抽取是可选增强，缺失必须显式报错而不是静默产出空摘要 | 2026-10-17 |
| D17 | 不做 exe 打包，交付源码 + `pip install -e .` | 纯 CLI 形态，打包带来的冻结态对账成本高于收益；扩展项再评估 | 2026-10-17 |
| D18 | 首期不做定时调度内置，只提供"单轮命令 + 系统任务计划示例" | 内置调度器会引入常驻进程与跨平台差异；用户用 cron/任务计划即可 | 2026-10-17 |
| D19 | 风险分级是产品自定规则（high/mid/low），不是监管评级 | 官方没有"公告风险级"字段；必须明示这是本工具的筛选标签，避免被读成投资评级 | 2026-10-17 |
| D20 | 快照/真值随仓库入库，运行时 SQLite/PDF 不入库 | 冻结资产要能被离线复现；运行时产物随用户数据变化，入库会污染 diff 且可能夹带原文 | 2026-10-17 |
