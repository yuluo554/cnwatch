## 二、冻结与脱敏纪律

1. **快照只保留本题字段**：`secCode/secName/announcementId/announcementTitle/announcementTime/adjunctUrl/adjunctType/announcementType`；丢弃与自选清单无关的批量内容。
2. **快照逐字节冻结**：生成后登记 sha256 到 `data/README.md` 或 `data/snapshots/MANIFEST.json`；重抓时连同 manifest 一起更新。
3. **`.gitattributes`**：快照与 PDF 类二进制标 `-text`，避免检出时行尾归一化导致 sha256 失配；源码统一 `text=auto eol=lf`。
4. **不含个人信息**：不抓 Cookie、不存登录态、不抓用户持仓以外的数据。
5. **不编造公告**：所有样本条目必须来自真实响应；只做“选哪些条目进样本”与“期望标签”。

## 三、真值台账设计

### 3.1 抓取层真值（A4）

```json
{
  "format": "cnwatch.fetch_truth",
  "format_version": 1,
  "snapshot": "announce-day-2026-10-16.json",
  "stock": {"code": "000001", "org_id": "gssz0000001"},
  "expected": {
    "announcement_ids": ["1225601360", "..."],
    "pages_at_page_size_30": 2,
    "total_announcement": 45
  }
}
```

- `expected` 由标注脚本从原始响应**独立复算**，不手抄。
- 禁止出现 `observed_*` 字段（否则基准退化为比对两份预计算答案）。

### 3.2 分类层真值（A6）

```json
{
  "format": "cnwatch.classify_truth",
  "format_version": 1,
  "rules_version": "v1",
  "samples": [
    {
      "announcement_id": "1225601360",
      "title": "关于副行长任职资格核准的公告",
      "expect": {"category": "category_dshgg_szsh", "tags": [], "risk_level": "low"},
      "evidence": "规则包 category_dshgg_szsh 的 pattern 命中"
    }
  ]
}
```

- 期望值必须可由 `title` + 规则包**独立复算**；
- 每条必须写 `evidence`（哪条规则命中），便于人工抽查；
- 反向样例单独一节，`expect.category` 可为 `unclassified`。

### 3.3 日报层真值（A9）

```json
{
  "format": "cnwatch.report_truth",
  "format_version": 1,
  "prev_date": "2026-10-15",
  "today_date": "2026-10-16",
  "expect": {
    "added": ["1225601360"],
    "removed": ["1225601000"],
    "baseline_created": false
  }
}
```

## 四、生成器与守门

| 生成器 | 产出 | 守门 |
|---|---|---|
| `tools/gen_snapshots.py` | A4/A9 的字段裁剪版 | `--check`：重生成与入仓件逐字节一致 |
| `tools/gen_rules.py` | A5 规则包 | `--check`；26 类齐全断言 |
| `tools/gen_truth.py` | A6/A9 真值 | `--check`；禁止 `observed_*` 字段 |

共同纪律：

1. 生成器**不读系统时钟**，日期由参数给出；
2. 排序键单点定义，生成侧与生产侧各一份独立实现（一致性靠逐字节测试，不共享 import）；
3. JSON 输出 `sort_keys=True, ensure_ascii=False, indent=2`，LF，结尾换行；
4. 生成产物不含时间戳；
5. 生成物是**输入的函数**，不得登记“目录里实际有几个文件”这类环境依赖事实。

## 七、不入库清单（硬约束）

- 任何用户真实持仓/备注；
- PDF 原文与全文；
- 运行时 SQLite；
- 日志中的请求头与 Cookie；
- 本机绝对路径（文档内一律相对路径）。
