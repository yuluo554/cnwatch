## 风险与缓冲

| 风险 | 触发信号 | 处置 |
|---|---|---|
| 接口结构变化 | 字段缺失/总数对不上 | 冻结新快照、更新解析、勘误表 |
| 快照重抓导致 sha256 漂移 | `--check` 红 | 连同 manifest 一起提交 |
| 规则标定样本不足 | 某类 0 正例 | 扩大窗口或标季节性，不编样本 |
| CI 首推失败 | 四矩阵同点红 | 先查接线（`set +e`/退出码断言），再查平台差异 |
| 跨版本差异 | 3.8 与 3.12 结果不同 | 底线语法用 3.8 写；CI 双版本必跑 |
